# FIAP - Data Science Course Repository

This repository contains projects and assignments developed throughout the Data Science program at FIAP (Faculty of Informatics and Administration).

## About the Course

**Program:** Data Science  
**Institution:** FIAP - São Paulo, Brazil  
**Focus Areas:** Artificial Intelligence, Analytics, Cloud & Data Platforms

## Program Overview

The Data Science program at FIAP provides comprehensive training in data intelligence and AI, covering the complete data lifecycle with strategic vision and results-oriented approach. The curriculum combines theoretical knowledge with hands-on practice through real-world challenges proposed by industry-leading companies.

### Core Competencies

- Data Analysis and Visualization
- Machine Learning and Deep Learning
- Artificial Intelligence and Predictive Modeling
- Natural Language Processing (NLP)
- Big Data Processing
- Cloud Computing (AWS, Azure, Google Cloud, Oracle Cloud)
- Data Pipelines and ETL
- Data Warehousing and Data Lakes
- NoSQL and Relational Databases
- Data Governance and Security
- Business Intelligence and Dashboards

### Technology Stack

**Programming and Data Science:**
- Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly, Scikit-learn, TensorFlow, PyTorch)
- SQL and PL/SQL

**Big Data and Processing:**
- Hadoop, Apache Spark, Databricks
- Apache Kafka, Apache NiFi

**Business Intelligence:**
- Power BI, Tableau, Looker

**Databases:**
- MongoDB, Cassandra, Redis, Neo4J

**Cloud Platforms:**
- AWS, Azure, Google Cloud, Oracle Cloud

**DevOps and Tools:**
- Git, GitHub
- Docker, Docker Compose
- Airflow, Prefect

## Certifications

The program awards professional qualification certificates at the end of each academic year:

1. Data Architecture and Data Quality Governance
2. Scalable Data Architectures and Big Data
3. Advanced Data Analysis and Interactive Data Visualization
4. Artificial Intelligence and Advanced Predictive Models
